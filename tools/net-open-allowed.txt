# Where the Makefile starts QEMU with --net-open (no `restrict=on`; INV-0230-1,
# tools/check-net-open.sh). NAME is the Makefile definition holding the line.
# Every one of them runs against the host-side servers of tools/test-httpd,
# which listen on 127.0.0.1 only and which the guest reaches at 10.0.2.2, or
# is a hand run that is not a step of make test. A new --net-open line needs a
# line here, with its reason.
NET_FETCH_RUN            fetch against the host test server (test-net, test-net-fetch)
test-net-fetch           the same, the DNS leg
test-net-lookup          the lookup test against the test server's name data, with a pcap
NET_POSIX_RUN            libposix and the POSIX network scripts against the test server
APPS_RUN                 curl and wget against the test server (test-apps)
test-python              Python's socket, ssl and urllib tests against the test server
NS_RUN                   NetSurf against the test server's pages (test-netsurf)
bench-net                a measurement against the test server, not a step of make test
hand-netsurf-wikipedia   a hand run that reaches the real Wikipedia; not a step of make test
