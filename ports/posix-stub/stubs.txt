# The stub zoraya-posix (ADR-0140): every function libc.a needs from the Rust
# half of ADR-0100, until TASK 6c writes it. One function per line: its kind,
# then its name. The kinds (ports/posix-stub/stubs.awk turns them into Rust):
#
#   int    returns -1 with errno ENOSYS
#   zero   returns 0 with errno ENOSYS (isatty: "not a terminal")
#   ptr    returns NULL with errno ENOSYS
#   sigerr returns SIG_ERR, (void *)-1, with errno ENOSYS
#   err    returns ENOSYS itself (functions that return an error number)
#   void   does nothing
#   raw    returns -ENOSYS (the system-call shim's convention, syscall.h)
#   trap   does not return: `brk #0x7a` ends the process with a fault
#   u32:N  an unsigned int variable with the value N
#
# Arguments are not named: on AAPCS64 a function that ignores its arguments
# may be called with any, variadic ones too.
#
# Section 1: the tier list's names that musl's retained files do not define

# `make check-ports` fails if this section and the archive disagree. Every one
# fails, including the few that need no system (htonl, sigemptyset, the
# posix_spawn attribute functions): they belong to the Rust half all the same.
