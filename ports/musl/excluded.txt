# Files of the retained directories that are not compiled (ADR-0100 item 2,
# ADR-0141). Each one makes a system call that ports/musl/zoraya/syscall.h does
# not route, so musl's code for it cannot work on Zoraya: the functions it
# defines come from zoraya-posix instead, or not at all when they are outside
# the tier list. The shim makes this list complete: a retained file that makes
# another system call fails to compile.
