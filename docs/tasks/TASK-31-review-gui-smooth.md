## Checked and found sound

- **Trust of the image (INV-0467-1).** `cursor_image` reads only `POINTER`, the scale and the palette of the
  appearance, a system setting. No client's memory or message reaches `SetCursor`. The hot spot is (0,0), matching
  `draw_pointer`'s tip. The image is opaque `0xFF` words over the palette's `0x00RRGGBB` pixels, which is right for
  `B8G8R8A8_UNORM` read as little-endian words.
- **Cursor queue.** `cursor_post`'s request matches `virtio_gpu_update_cursor`: 56 bytes, header 24, position 16
  (scanout, x, y, padding), resource, hot x, hot y, padding. A slot is rewritten only after the device returned it.
  `Queue::take` refuses a used index above the outstanding count and an id never offered, so `1 << used.head` cannot
  overflow (the id is below 16). `offer` refuses a head that is still out. `VIRTQ_AVAIL_F_NO_INTERRUPT` is written
  once, before `ready`, and nothing writes the flags again. The queue, the requests and the image do not overlap the
  control queue's request and response (separate pages, `SHARED_MEMORY` 69632). The device reads the image's backing
  only during `TRANSFER_TO_HOST_2D`, which is synchronous on the control queue, and the transfer finishes before
  `UPDATE_CURSOR` is offered. Resource 3 never collides with the display's 1 and 2 (`3 - RESOURCE`).
- **Protocol decoding.** `Data<'a, CURSOR_BYTES>` is a length bounded on decode and on encode. `gpud` also requires
  exactly `CURSOR_BYTES` and a hot spot below 64. `gpud`'s message buffer (`CURSOR_BYTES + 256`) holds the largest
  `SetCursor`. A message with a handle on ordinal 5 or 6 has the handle closed. A `MoveCursor` that does not decode
  is dropped with no reply. The compositor's `out` is `MAX_WIRE_MESSAGE`, so encoding cannot fail.
- **Frame pacing.** `frame_held` never holds a round with a commit waiting, so commits are answered in their round and
  the loop cannot spin on a readable client. `frame_due` is folded into `step`'s deadline. A held round still sends
  the unflushed damage and the cursor's place.
- **The copy of a moved window (apart from R5).** It needs the window to be topmost with nothing shown above it (no
  popup, sheet, card, switcher, carried tag, command tags or software pointer) and nothing else damaged since the last
  frame. Chrome and body are opaque inside the inset. `src` and `dst` are both clipped to the work area, so the
  indices into `pixels` stay in bounds. Rows are copied in an order that never reads a row already overwritten, and
  `copy_within` handles the overlap within a row. `Rect::minus` is tested for coverage and disjointness. The equality
  tests are not vacuous: they assert that blits happened, and compare every round's frame with a whole compose at
  both scales, including under the bar and the dock.
- **Unsafe.** The diff adds no `unsafe` block.
- **Measurement.** It is off unless `/config/gui-measure` exists, writes at most 64 lines a boot, and keeps only
  counters, no buffers.
