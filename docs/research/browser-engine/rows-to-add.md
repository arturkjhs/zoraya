# Rows to add to `index.md` and `invariants.md` for ADR-0410 to ADR-0421

Generated from the ADR files on 2026-11-14 (TASK-33), after the review's fixes (`review-notes.md`). TASK-33 allows changes only under
`docs/adr/0410-*` to `docs/adr/0429-*` and `docs/research/browser-engine/`, so the rows are here for whoever lists the
ADRs. The invariant rows' first four columns are copied from each ADR's `## Invariants` section, as `make adr-check`
(INV-0001-4) requires once an ADR is accepted. Until the index rows are added, `make adr-check` reports twelve
`INV-0001-5 ... is not listed` errors for these files and nothing else (run with the prebuilt
`target/debug/zoraya-adr-check docs` of this clone, not rebuilt, because TASK-33 runs no `make` or `cargo`).

ADR numbers 0422 to 0429 are unused.
