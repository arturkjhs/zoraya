- [M10] musl, `src/env/__init_tls.c`, https://raw.githubusercontent.com/kraj/musl/master/src/env/__init_tls.c, primary, checked 2026-11-02. `static_init_tls` walks the program headers from `aux[AT_PHDR]`, `aux[AT_PHNUM]` entries with stride `aux[AT_PHENT]`, for `PT_TLS`; uses the static `builtin_tls` when the block fits and otherwise `__syscall(SYS_mmap2 ...)` (`SYS_mmap` where `mmap2` is absent); `__init_tp` calls `__set_thread_area` and `SYS_set_tid_address`, and a failure is `a_crash()`.
- [M9] musl, `arch/aarch64/crt_arch.h`, https://raw.githubusercontent.com/kraj/musl/master/arch/aarch64/crt_arch.h, primary, checked 2026-11-02. `_start` zeroes `x29` and `x30`, passes `sp` in `x0` and `_DYNAMIC` in `x1`, aligns the stack to 16 and branches to `_start_c`.

"A portable C standard library written in Rust and is under heavy development"; supports Redox and Linux; `src/platform/redox` and `src/platform/linux`; `redox-rt` "provides much of the code that enables POSIX on Redox" and is the backend of the Redox platform.

- [R3] Redox OS, relibc `src/platform/`, https://github.com/redox-os/relibc/tree/master/src/platform, primary, checked 2026-11-02. Directories `allocator`, `linux`, `pal`, `redox`.
- [R4] Redox OS, relibc `src/platform/pal/mod.rs`, https://github.com/redox-os/relibc/blob/master/src/platform/pal/mod.rs, primary, checked 2026-11-02. - [C1] Cygwin, User's Guide, "Highlights of Cygwin functionality" (source `winsup/doc/highlights.xml`), https://github.com/cygwin/cygwin/blob/main/winsup/doc/highlights.xml (mirror of cygwin.com), primary, checked 2026-11-02. `fork` is "a non-copy-on-write implementation similar to what was present in early flavors of UNIX": a suspended child by `CreateProcess`, `.data` and `.bss` copied, then stack and heap; the child must have the same address space layout; retries on layout conflicts; "occasional fork failures are inevitable"; fork "will almost certainly always be inefficient under Win32"; switching a compiler driver to spawn "increased compilation speeds by twenty to thirty percent".

## POSIX semantics

Read from the Linux man-pages project's repository, https://github.com/mkerrisk/man-pages, since `pubs.opengroup.org` and `man7.org` were not reachable. Each page is primary for Linux and quotes or paraphrases POSIX.1; where only Linux behaviour is meant the note says so.

- [P1] `pipe(7)`, https://github.com/mkerrisk/man-pages/blob/master/man7/pipe.7, checked 2026-11-02. Capacity 16 pages (65,536 bytes) since Linux 2.6.11, changeable with `F_SETPIPE_SZ`; `PIPE_BUF` at least 512 by POSIX, 4096 on Linux; writes of at most `PIPE_BUF` bytes are atomic (blocking: all written; non-blocking: all or `EAGAIN`); larger writes may interleave and, non-blocking, may be partial; `read` returns 0 when every write end is closed; a write with no read end gives `SIGPIPE`, or `EPIPE` if ignored.
- [P2] `fifo(7)`, https://github.com/mkerrisk/man-pages/blob/master/man7/fifo.7, checked 2026-11-02. Opening a FIFO normally blocks until the other end is opened; a non-blocking read-only open succeeds at once; a non-blocking write-only open fails with `ENXIO` unless a reader exists; under Linux opening a FIFO for reading and writing succeeds, which POSIX leaves undefined.
- [P3] `fork(2)`, https://github.com/mkerrisk/man-pages/blob/master/man2/fork.2, checked 2026-11-02. The child's descriptors refer to the same open file descriptions (shared offset and status flags); pending signals cleared; timers, record locks, memory locks and outstanding asynchronous I/O not inherited; one thread; same process group and session; Linux implements it with copy-on-write pages, "so the only penalty that it incurs is the time and memory required to duplicate the parent's page tables".
- [P4] `dup(2)`, https://github.com/mkerrisk/man-pages/blob/master/man2/dup.2, checked 2026-11-02. `dup` refers to the same open file description, sharing offset and status flags; the duplicate's close-on-exec flag is off; `dup2` closes `newfd` first, atomically, and does nothing when `oldfd == newfd`; `dup3` adds `O_CLOEXEC` and refuses equal descriptors.
- [P5] `setpgid(2)`, https://github.com/mkerrisk/man-pages/blob/master/man2/setpgid.2, checked 2026-11-02. `pid` 0 is the caller, `pgid` 0 the target's own pid; `EACCES` after a child's `execve`, `EPERM` for a session leader or a group in another session, `ESRCH` when `pid` is neither the caller nor a child; only the foreground group reads the terminal, a background group that reads gets `SIGTTIN`.
- [P6] `wait(2)`, https://github.com/mkerrisk/man-pages/blob/master/man2/wait.2, checked 2026-11-02. `pid` less than -1, -1, 0, positive; `WNOHANG`, `WUNTRACED`, `WCONTINUED`; the status macros; `ECHILD`; with `SIGCHLD` set to `SIG_IGN` children do not become zombies and `wait` fails with `ECHILD` after they end.
- [P7] `execve(2)`, https://github.com/mkerrisk/man-pages/blob/master/man2/execve.2, checked 2026-11-02. The pid is unchanged; caught signals reset to default, ignored stay ignored; descriptors stay open unless close-on-exec; `#!interpreter [optional-arg]`, 255 characters since Linux 5.1, four levels of nesting; `ENOEXEC`; `ARG_MAX` from `RLIMIT_STACK` with a floor of 32 pages.
- [P8] `credentials(7)`, https://github.com/mkerrisk/man-pages/blob/master/man7/credentials.7, checked 2026-11-02. Sessions, session leader by `setsid`, the controlling terminal established when the leader first opens a terminal, at most one controlling terminal per session, one foreground job, `SIGTTIN` on a background read and `SIGTTOU` with `TOSTOP`, "a strict two-level hierarchy", keyboard signals go to the foreground job.
- [P9] `termios(3)`, https://github.com/mkerrisk/man-pages/blob/master/man3/termios.3, checked 2026-11-02, first part only (the page view was truncated). `ISIG`: INTR, QUIT and SUSP generate `SIGINT`, `SIGQUIT`, `SIGTSTP`; `TOSTOP` sends `SIGTTOU` to a background writer; `NOFLSH`.
- [P10] `tcgetpgrp(3)` and `tcsetpgrp(3)`, https://github.com/mkerrisk/man-pages/blob/master/man3/tcgetpgrp.3, checked 2026-11-02. The fd must be the caller's controlling terminal; the group must be a non-empty group of the caller's session; a background caller gets `SIGTTOU` to its whole group unless blocked or ignored; `EBADF`, `EINVAL`, `ENOTTY`, `EPERM`.
- [P11] `select(2)`, https://github.com/mkerrisk/man-pages/blob/master/man2/select.2, checked 2026-11-02. `pselect` replaces the signal mask for the duration of the call, which closes the race between testing a flag and blocking; `EINTR` when a signal is caught; a descriptor is readable when a read will not block, including at end of file; `pselect` leaves its timeout unchanged.
- [P12] `signal(7)`, https://github.com/mkerrisk/man-pages/blob/master/man7/signal.7, checked 2026-11-02. The standard signal numbers and default actions on x86 and ARM (`SIGHUP` 1 Term, `SIGINT` 2, `SIGQUIT` 3 Core, `SIGILL` 4, `SIGTRAP` 5, `SIGABRT` 6, `SIGBUS` 7, `SIGFPE` 8, `SIGKILL` 9, `SIGUSR1` 10, `SIGSEGV` 11, `SIGUSR2` 12, `SIGPIPE` 13, `SIGALRM` 14, `SIGTERM` 15, `SIGCHLD` 17 Ign, `SIGCONT` 18, `SIGSTOP` 19, `SIGTSTP` 20, `SIGTTIN` 21, `SIGTTOU` 22, `SIGURG` 23 Ign, `SIGXCPU` 24, `SIGXFSZ` 25, `SIGWINCH` 28 Ign); `SA_RESTART` restarts an interrupted call, otherwise `EINTR`; `SIGKILL` and `SIGSTOP` cannot be caught, blocked or ignored.
- [P13] `kill(2)`, https://github.com/mkerrisk/man-pages/blob/master/man2/kill.2, checked 2026-11-02. `pid` positive, 0 (the caller's group), -1, less than -1 (the group `-pid`); signal 0 checks existence; `EINVAL`, `EPERM`, `ESRCH`; POSIX requires `kill(-1, sig)` to reach every process the caller may signal, and on Linux the call does not signal the caller itself.
- [P14] `setsid(2)`, https://github.com/mkerrisk/man-pages/blob/master/man2/setsid.2, checked 2026-11-02. A new session and group with no controlling terminal; `EPERM` for a process group leader.
- [P15] `pipe(2)`, https://github.com/mkerrisk/man-pages/blob/master/man2/pipe.2, checked 2026-11-02. `pipe2` flags `O_CLOEXEC`, `O_DIRECT` (packet mode) and `O_NONBLOCK`.
- [P16] `fcntl(2)`, https://github.com/mkerrisk/man-pages/blob/master/man2/fcntl.2, checked 2026-11-02. `F_DUPFD`, `F_DUPFD_CLOEXEC`, `F_GETFD`/`F_SETFD` with `FD_CLOEXEC` per descriptor, `F_GETFL`/`F_SETFL` changing only `O_APPEND`, `O_ASYNC`, `O_DIRECT`, `O_NOATIME` and `O_NONBLOCK`, which are shared by duplicates of one open file description.
- [P17] `mkfifo(3)`, https://github.com/mkerrisk/man-pages/blob/master/man3/mkfifo.3, checked 2026-11-02. Creates a FIFO with `mode & ~umask`; both ends must be open before I/O; `EEXIST`.

## GNU make

- [K1] GNU make, `src/posixos.c`, https://github.com/mirror/make/blob/master/src/posixos.c (mirror of git.savannah.gnu.org), primary, checked 2026-11-02. `jobserver_setup`: FIFO style `mkfifo` in the temp directory then `open(O_RDONLY|O_NONBLOCK)` and `open(O_WRONLY)`; pipe style `pipe()`; both ends close-on-exec; one token byte per slot; auth strings `fifo:PATH` and `R,W`; `-2,-2` for a disabled pipe jobserver; `jobserver_acquire`: `pselect` with an empty mask then a non-blocking one-byte `read`, retrying on `EAGAIN`; `jobserver_release` writes one byte; `jobserver_pre_child`/`post_child` clear and set `FD_CLOEXEC` for recursive children, pipe style only.
- [K2] GNU make manual, `doc/make.texi`, https://raw.githubusercontent.com/mirror/make/master/doc/make.texi, primary, checked 2026-11-02, read in three parts. "POSIX Jobserver": `--jobserver-auth=fifo:PATH` and `--jobserver-auth=R,W`, one implicit slot per process, read one character for a slot and write the same character back, a negative fd disables the jobserver, `--jobserver-style`. "Interrupting or Killing make": on a fatal signal make may delete the target whose recipe was running if its modification time changed since make first checked it, unless `.PRECIOUS`. "Rule Syntax": a target is out of date if it does not exist or is older than any prerequisite.
- [K3] GNU make, `COPYING`, https://github.com/mirror/make/blob/master/COPYING, primary, checked 2026-11-02. GNU General Public License version 3.
