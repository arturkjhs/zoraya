# Rows to add to `index.md` and `invariants.md` for ADR-0450 to ADR-0455

Generated from the ADR files on 2026-11-15 (TASK-35), after the review's fixes ([`review-notes.md`](review-notes.md)).
TASK-35 allows changes only under `docs/adr/0450-*` to `docs/adr/0459-*` and `docs/research/rust-std/`, so the rows are
here for whoever lists the ADRs. The invariant rows' first four columns are copied from each ADR's `## Invariants`
section, as `make adr-check` (INV-0001-4) requires once an ADR is accepted; the Status column is a proposal (no planned
stage builds these yet; the backlog would hold the part). Until the index rows are added, `make adr-check` reports six
`INV-0001-5 ... is not listed` errors for these files and nothing else.

ADR numbers 0456 to 0459 are unused.

ADR-0450 proposes to supersede ADR-0418 item 4 only; if it is accepted, ADR-0418's index row gains a note (the
architect's). ADR-0453 item 3 changes INV-0411-4 and ADR-0310 item 3 for randomness only.
