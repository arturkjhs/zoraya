# Invariants from all ADRs

Every invariant from every ADR in `docs/adr/`, with the ADR it comes from and its stated checking method. Generated from the `## Invariants` sections; regenerate rather than edit by hand. None of these checks is implemented yet (TASK-03 is out of scope for implementation); ADR-0001 rule 6 says how an invariant becomes a check once its ADR is accepted.
