# Invariants from all ADRs

Every invariant from every ADR in `docs/adr/`, with the ADR it comes from, its stated checking method and its status. The first four columns are copied from the `## Invariants` sections and must match them word for word (INV-0001-4, checked by `make adr-check`); change the ADR, not this table. ADR-0001 rule 6 says how an invariant becomes a check once its ADR is accepted.

**Status** is `checked` (with the command that checks it), `replaced by INV-NNNN-k` (an accepted ADR replaced the rule, and the row stays as the record) or `not yet applicable (stage N)`, where N is the roadmap stage in [`../design.md`](../design.md#roadmap) that first builds the code the check would test, or `not yet applicable (until <what>)` when no planned stage builds it and `docs/backlog.md` holds the item. The stage numbers are a planning estimate made in TASK-04, not a decision. `make adr-check` prints a warning for every invariant of an accepted ADR that is not `checked`.
